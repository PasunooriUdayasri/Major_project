# Smart Incubator for Poultry Farming

## Project Overview
The Smart Incubator for Poultry Farming is an automated system designed to provide a controlled environment for hatching and raising poultry chicks. Using sensors to monitor temperature and humidity, combined with a NodeMCU microcontroller for real-time adjustments, the system ensures optimal conditions for chick development. This project integrates IoT technology for remote monitoring and control, reducing manual effort, improving hatch rates, and supporting sustainable poultry farming.

## Features
- Automatic temperature and humidity regulation using DHT11 sensors and relays.
- Real-time environmental data display via an LCD/OLED screen.
- IoT-based remote monitoring and control using NodeMCU and Blynk app.
- Automated fan and bulb control to maintain ideal incubation conditions.
- Energy-efficient operation with minimized human intervention.
- Data logging support for analysis and optimization.
- Suitable for small to medium-scale poultry farming.

## Hardware Components
- NodeMCU ESP8266 microcontroller
- DHT11 temperature and humidity sensor
- Light sensor (LDR)
- Relay module for switching bulb and fan
- Heating bulb and cooling fan
- Power supply unit

## Software Components
- Arduino IDE for programming NodeMCU
- Blynk platform for IoT connectivity and remote monitoring
- Custom control algorithms for environmental regulation

## Installation
1. Assemble the hardware components as per the block diagram.
2. Install Arduino IDE on your computer.
3. Connect the NodeMCU to the computer via USB.
4. Load the provided Arduino code into the IDE.
5. Configure Wi-Fi credentials and Blynk authentication tokens in the code.
6. Upload the code to the NodeMCU.
7. Set up the Blynk app on your smartphone for remote monitoring.

## Usage
- Power on the incubator system.
- Sensors will monitor temperature and humidity continuously.
- The NodeMCU will automatically adjust fan and bulb operation to maintain set parameters.
- Monitor conditions locally via LCD or remotely through the Blynk app.
- Receive alerts on deviations in environmental parameters.
- Periodically maintain sensors and hardware for optimal performance.

## Advantages
- Consistent and precise incubation environment.
- Reduced labor and increased efficiency.
- Improved hatchability and chick health.
- Remote access and monitoring.
- Scalable and cost-effective for various farm sizes.

## Future Scope
- Integration of AI and machine learning for predictive environmental adjustments.
- Automated feeding and watering systems for chicks.

- Enhanced energy-efficient components and renewable energy integration.
